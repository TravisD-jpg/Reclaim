# Reclaim

Term project for UAkron 475/575 Database Management. Read these before working:

- `docs/project-spec.md` — **source of truth** (assignment, rubric, Stage 1–3 commitments). Implementation must match it; when it can't, add a row to "Deviations from spec" in `docs/codebase.md`.
- `docs/codebase.md` — how the code works now. **Update it in the same change** as any code change (endpoints, tables, pages, setup steps, feature status).
- `docs/ai-usage.md` — the course requires disclosure of all AI use. Add one table row per user prompt: date, **exact prompt** verbatim, what it did, inaccuracies/corrections (keep each cell to one or two short sentences). Leave "What We Learned" blank for the students. Skip any prompt the user says not to log.

Code readability is graded. Keep code clean and consistent, and remove template leftovers, keep comments short, don't leave long comments in the middle of code blocks.
